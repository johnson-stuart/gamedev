# User Interface

## HUD

The HUD so far is a **CanvasLayer** node inside of player.gd with a **Button** child node. The button node has an option for an icon, where a .png image can be inserted. 

# HP Bars

Player HP bars currently exist in the player scene in a CanvasLayer.

Enemy HP bars need to be projected above the enemies heads, so they exist in a **SubViewport** that's projected into a Sprite3D located above the enemy.
